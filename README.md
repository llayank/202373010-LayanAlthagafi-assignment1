# Personal Portfolio Web Application

A responsive, minimalist personal portfolio web application 

---

## Project Description
This portfolio serves as an entry-level professional showcase for software engineering projects. It is structured into three primary semantic sections:
* **About Me:** A clean biographical introduction featuring an adaptive time-of-day greeting.
* **Featured Projects:** Highlights academic applications with technology tags and placeholder previews.
* **Contact:** An accessible interactive contact form with client-side feedback.


---

## AI Usage Summary
AI (Gemini) was used as a supportive pair-programming assistant to brainstorm responsive layout patterns, suggest color palette, and troubleshoot JavaScript logic for theme toggling and form handling. All suggestions were reviewed, customized, and manually tested to ensure code quality and integrity. For full details on prompts, benefits, and challenges, see [`docs/ai-usage-report.md`](docs/ai-usage-report.md).
