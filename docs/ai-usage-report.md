# AI Usage Report

## 1. Tools Used & Use Cases
* **Tool:** Gemini (Google)
* **Use Cases:**
  * **Ideation & Layout Assistance:** Brainstorming the architectural layout and semantic HTML structure required for an entry-level software engineering portfolio.
  * **CSS & Color Palettes:** Recommending modern CSS variables and color combinations to achieve a minimalist visual aesthetic.
  * **Interactivity Brainstorming:** Exploring logic implementations for JavaScript features, including time-of-day greetings and dark/light theme switching.
  * **Documentation Guidance:** Outlining standard formatting and requirements for technical documentation.

## 2. Benefits & Challenges

### Benefits
* **Faster Workflow:** The AI saved a lot of time by quickly setting up the basic HTML structure and the project folders.
* **Helpful Learning Assistant:** It clearly explained how to use CSS Grid and Flexbox to make the website adapt smoothly to mobile and desktop screens.
* **Design Ideas:** It was very helpful for brainstorming nice color palettes and suggesting hex codes for the purple and warm beige theme.
* **Easy Debugging:** Whenever a script or CSS rule didn't work as expected, asking the AI helped identify the syntax mistake right away.

### Challenges
* **Generic Outputs:** The initial code from the AI was too generic, so I had to rewrite the text and personalize the project details myself.
* **Color Preferences:** The AI first defaulted to blue colors, so I had to guide it step-by-step to get the exact shades of purple and beige that I wanted.
* **Overcomplication:** Sometimes the AI suggested extra features that were not requested in the assignment, which meant I had to filter them out to keep the code clean and focused.
* **Manual Adjustments:** I couldn't just copy and paste everything; I had to test the responsive layout on my own screen using browser DevTools to make sure it looked right.

## 3. Learning Outcomes
* **Workflow Improvements:** Learned how to treat AI as a collaborative pair programmer for brainstorming and debugging rather than as a source of finished output.
* **Code Structuring:** Improved ability to design modular, accessible semantic markup that complies with web standards and accessibility guidelines.

## 4. Responsible Use & Modifications
* **Code Review & Verification:** Every line of HTML, CSS, and JavaScript was reviewed, executed locally, and tested across viewports using browser DevTools to ensure correctness and compatibility.
* **Customization:** Heavily adapted styles, adjusted spacing and layout hierarchies, removed unnecessary placeholder sections, and refined interactive triggers to retain complete control over the application's final functionality.
